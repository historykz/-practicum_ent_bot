🏆 Оценка

Какие бывают ключи
  • {"type":"pairs","answer":{"a":"1","b":"2"}} — сопоставление: объект ключ→значение, баллы за каждую верную пару.
  • {"type":"fields","answer":{"p1":["Абай","Абай Кунанбаев"],"p2":"1845"}} — заполнение пропусков: по каждому полю один или несколько допустимых ответов, баллы за каждое поле.
  • {"type":"sequence","answer":["a","b","c"]} — последовательность: важен порядок.
  • {"type":"set","answer":["a","c"]} — набор без порядка (например, выбрать все верные).
  • {"type":"number","answer":3.14,"tolerance":0.01} — число с допуском.
  • {"type":"exact","answer":…} — любое JSON-значение целиком.
  • Регистр букв и лишние пробелы не важны; чтобы учитывать регистр, добавьте "case_sensitive": true.

🖼 Картинки задания

Загруженные картинки доступны заданию по адресу из списка. До 5 МБ: png, jpg, gif, webp, svg.

    📘 Как задание общается с платформой (SmartENT)
    • SmartENT.ready(function (progress, ctx) { … }) — запуск: сохранённый прогресс ученика (или null).
    • SmartENT.saveProgress(объект) — сохранить прогресс на сервере (до 50 КБ); при возврате ученик продолжит с места.
    • SmartENT.submit(ответ) — отправить ответ на проверку сервером (задание «Влияет на оценку»).
    • SmartENT.onResult(function (r) { r.score, r.max, r.percent, r.correct }) — результат проверки.
    • SmartENT.reportScore(баллы, максимум) — результат, посчитанный самим заданием: сохраняется как тренировочный.
    • Задание работает в изолированном фрейме: нет доступа ко входу, cookie, данным других учеников и админке, нет сетевых запросов. Скрипты и стили можно подключать с cdn.jsdelivr.net, cdnjs.cloudflare.com, unpkg.com, cdn.tailwindcss.com, code.jquery.com; картинки — с сайта, по https или data:.
    • Если задание хранит данные в localStorage (так часто делает ИИ), это работает: платформа сохраняет их на сервере как прогресс ученика.
    • Водяной знак ученика рисует платформа поверх задания, в код его добавлять не нужно.
